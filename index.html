Alika Ko Setup Kaise Karein?

Google AI Studio se free API key nikalne se lekar Alika ko awaken karne tak ke aasan steps:

STEP 01

Google AI Studio Kholein

Apne browser me Google AI Studio open kijiye aur top-left par diye gaye "+ Create API key" button par click kijiye. Yeh sabhi ke liye Google se 100% free hai.

STEP 02

API Key Generate Karein

Pop-up screen aane par apna Google Cloud Project chun lijiye aur "Create API key in existing project" par click karke apni private key ko clipboard me copy kar lein.

STEP 03

Alika Setup Ko Launch Karein

Download kiye huye Alika.Setup.exe par double click karein. Screen par Alika ka futuristic boot screen dikhega: "Alika Starting up... Made with ❤️ by Karan".

STEP 04

Gemini API Key Save Karein

Alika window me apni copy ki hui Google API key paste karein aur "Save Key" dabayein. Key aapke system me safely encrypt ho jayegi.

STEP 05

Alika is Ready to Assist!

Congratulations! Alika active ho chuki hai. Mic on karke seedha bolna start karein ya screen share karke complex tasks me live help lein!
