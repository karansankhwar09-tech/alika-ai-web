✦ DATA TRANSPARENCY & TRUST

Packet Path:
Where Does Your Data Actually Go?

We do not make false claims that "everything stays local". Here is the precise, verified technical reality of what stays on your PC, what transmits to Google Gemini for multimodal reasoning, and what never happens.

Local Device Storage & Execution

Zero External Developer Server Sync
🔑 BYOK Google AI Studio Key

Stored on your local machine in secrets.json. Your key is never sent to or intercepted by any developer server.

🧠 Daily Memories & Study Notes

Persisted strictly in a dedicated local SQLite file (alika_daily_memory.sqlite). You retain full physical ownership of the database.

🖥️ Windows PC Automation Agent

FastAPI agent executes on 127.0.0.1:8765. Interacts with Windows UIA and hardware APIs strictly on loopback.

📸 Volatile Screen Frames (MSS)

When triggered (Alt + Q), captured frame resides in volatile RAM only. Immediately discarded upon completion—never archived locally.

Direct External API Communications

Direct TLS 1.3 Encrypted WebSocket to Google Endpoints
🎙️ Real-Time Voice Audio Packets

Streamed as PCM audio via TLS-encrypted WebSockets directly to Google Gemini Live API for real-time speech-to-speech reasoning.

🖼️ Explicit Screen Query Frames

When you press Alt + Q ("Ask About Screen"), the captured desktop frame is transmitted directly to Google Gemini Live for visual understanding.

🔍 Real-Time Web Search Queries

When web search tool is invoked, text search terms are dispatched to standard search endpoints to fetch live context.

💬 Community Discussions (Giscus)

Website feedback threads are hosted publicly on GitHub Discussions via the Giscus app subject to GitHub terms.

Architectural Non-Negotiables

Strict Prohibitions Engineered into ALIKA AI
🚫 No Intermediate Developer Servers

ALIKA does not operate middleman servers, proxy brokers, or API gateways. Traffic flows directly between your machine and Google.

🚫 No Passive 24/7 Screen Recording

Screen is read strictly upon on-demand user hotkey (Alt + Q). There is zero continuous screen broadcasting, recording, or archival.

🚫 No Advertising Beacons or Trackers

Neither the website nor the desktop application contains third-party ad networks, telemetry trackers, or commercial user profiling beacons.

🚫 No Hidden Keyloggers or Directory Scans

The local automation agent operates only on authorized UI automation targets and system hardware sliders—never private files or keystrokes.

System Prerequisites • Ready Before You Begin

Standard microphone & speakers/headphones. Default Windows communication device.

STEP 01

Google AI Studio Kholein

Apne browser me Google AI Studio (aistudio.google.com) open kijiye aur top-left par diye gaye “+ Create API key” button par click kijiye. Yeh Google AI Studio free tier ke sath aasaani se use kiya ja sakta hai.

Gemini API Key Save Karein

TROUBLESHOOTING & COMMON QUESTIONS

Setup Troubleshooting Guide

Click on any issue below for immediate verified resolution steps.

ALIKA AI is an independent open-source desktop tool. Because purchasing an expensive commercial EV (Extended Validation) code-signing certificate is cost-prohibitive for indie creators, Windows SmartScreen flags newly downloaded executable files.

Resolution: Click “More info” on the SmartScreen blue banner, then click “Run anyway”. The release binary is an official standalone installer compiled directly from source.

Ensure that you copied the complete API key string starting with AIzaSy... directly from Google AI Studio. Make sure no leading or trailing spaces were accidentally included.

Checklist: (1) Verify your Google Cloud project is in good standing. (2) Confirm that the Generative Language API is active. (3) If you regenerated your key, re-enter it in ALIKA AI settings.

Windows may block desktop applications from reading audio hardware by default if system-level privacy restrictions are active.

Fix: Open Windows Settings → Privacy & security → Microphone. Verify that “Let desktop apps access your microphone” is toggled ON. Set your desired input as the Default Communication Device.

Global hotkey hooks can be blocked if another application has exclusive focus with Administrator privileges or if third-party software (such as gaming overlays) reserves the same keyboard shortcut.

Fix: If your active game or IDE runs as Administrator, launch ALIKA AI as Administrator as well so Windows allows hotkey capture across elevated windows.

ALIKA AI runs a private Win32 automation loop on http://127.0.0.1:8765. This port binds exclusively to your local device loopback interface and is never exposed to external networks.

Fix: If you run third-party security suites (e.g. Norton, Kaspersky, ZoneAlarm), ensure internal localhost loopback traffic (127.0.0.1) is permitted.
